📘 Module 20 - Web Project
This project contains the web development corresponding to Module 20, including HTML pages, CSS styles and JavaScript functionality.

🎯 Objective
The goal is to develop a complete website with several interconnected pages, applying best practices in layout, responsive design and code organisation.
The following elements are covered:

Semantic HTML5 structure
CSS3 styling
JavaScript interactivity
Responsive hamburger menu
Scroll animations

JavaScript
